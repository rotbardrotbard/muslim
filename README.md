# «Умма в ОК» — мини-приложение для Одноклассников

Исламский мини-апп для платформы ОК: время намаза, кибла, Коран, основы ислама, календарь Хиджры, Рамадан и карта мечетей. Клиент — единый статический `index.html` (без сборки), серверная часть — лёгкий Flask-шаблон для пуш-напоминаний.

## Структура репозитория

| Файл | Назначение |
|---|---|
| `index.html` | production-версия приложения: единый HTML-файл (дизайн утверждённого прототипа v0.6), 9 языков, пуш-настройки, полная база мечетей, реальный расчёт времени намаза, подключён OK JS SDK |
| `push_server/push_server.py` | рабочий шаблон сервера напоминаний (Flask): подписка пользователей + cron-рассылка через OK REST API `notifications.sendSimple` |
| `push_server/requirements.txt` | зависимости сервера (flask, requests) |
| `README.md` | этот чеклист |

## Быстрый старт

**Клиент.** `index.html` — самодостаточный файл: откройте его в браузере, ничего собирать не нужно. Вне ОК приложение работает автономно (без `FAPI.init`).

**Пуш-сервер.**

```bash
cd push_server
pip install -r requirements.txt
python push_server.py   # по умолчанию http://127.0.0.1:5000
```

Эндпоинты: `POST /api/subscribe` (подписка), `POST /api/unsubscribe` (отписка), `GET /api/cron` (ежеминутная рассылка из cron).

**Публикация.** Для каталога ОК нужен HTTPS-хостинг с `index.html` (URL фрейма указывается в настройках приложения, см. п. 2–3 ниже). Подойдёт GitHub Pages, любой статический хостинг или VPS. Секретный ключ ОК хранить только на сервере пушей — в клиенте его быть не должно.

## Что внутри

### 1. Что уже готово в сборке

- **16 экранов** онбординга и сервиса: приветствие → язык → город → мазхаб + пуши → главная → намаз (трекер) → кибла → Коран (список/чтение) → основы (6 уроков) → календарь Хиджры → Рамадан → мечети → настройки → «нет гео».
- **9 языков** (RU KK UZ KY TG TT BA CE AV): интерфейс, уроки, хадисы, аят и дуа дня, названия сур, города, склонения. Выбор языка сохраняется и применяется мгновенно.
- **Полная база мечетей**: 11 149 объектов (10 028 мечетей + 1 121 молельная комната) в 1 392 городах России, Казахстана и Средней Азии — выгрузка из открытой базы проекта **«Где намаз» (gdenamaz.ru)** от 05.11.2026, только объекты со статусом active (проверены модерацией gdenamaz.ru). Карта Leaflet + кластеры, фильтры по типу и городу, дистанция, часы работы и удобства.
- **Реальный расчёт времени намаза** на устройстве: метод **ДУМ России (фаджр 18° / иша 15°)**, аср по выбранному мазхабу (ханафи 2 / шафии 1), для высоких широт — снижение угла. Часовые пояса для 70+ крупнейших городов встроены, для остальных — пояс устройства. Времена Фаджра/Асра/Иши совпадают с официальными расписаниями в пределах 0–2 минут, восход/магриб — до 5 минут (проверено по moynamaz.org на 8 городах).
- **Кибла и расстояние до Каабы** — реальный расчёт по координатам города (Москва 176°, Казань 195°, Уфа 207°).
- **Напоминания**: переключатель, интервал «за 10/15/30 минут», демо-уведомление в стиле пуша ОК, планировщик на открытой сессии. Реальная рассылка — серверная (п. 4).
- **OK JS SDK**: подключён `https://api.ok.ru/js/fapi5.js`, `FAPI.init` вызывается с параметрами запуска; вне ОК приложение работает автономно.

## 2. Регистрация приложения в ОК

1. Откройте центр разработчиков: **https://ok.ru/devaccess** → «Создать приложение».
2. Тип: **«Внешнее приложение» (iframe / мини-приложение)**.
3. После создания получите ключи:
   - **application_key** (публичный);
   - **application_secret_key** (секретный) — хранить только на сервере.
4. Если приложение открывается не во фрейме, запросите запуск во фрейме: **api-support@ok.ru**.
5. В настройках приложения укажите **URL фрейма** — HTTPS-адрес, где размещён `index.html`.

## 3. Размещение и параметры запуска

- Хостинг — **HTTPS**, без редиректов на внешние сайты из фрейма.
- При запуске ОК передаёт параметры: `uid`, `api_server`, `apiconnection`, `application_key`, `session_key`, `custom_args` (apiok.ru/apps/rules → «Параметры запуска»).
- Сборка читает их через `FAPI.Util.getRequestParameters()` и передаёт в `FAPI.init`. После **каждого внутреннего перехода** фрейма повторяйте `FAPI.init`.
- Язык при первом запуске можно брать из локали ОК и подставлять в `setLang()`.

## 4. Пуш-напоминания (рабочая схема)

1. При первом запуске запросите OAuth-токен пользователя:
   `https://connect.ok.ru/oauth/authorize?client_id=<app_id>&scope=VALUABLE_ACCESS;LONG_ACCESS_TOKEN&redirect_uri=...`
2. Приложение отправляет `POST /api/subscribe` (uid, город, язык, `minutes_before`, `access_token`) на ваш сервер.
3. **Cron раз в минуту** вызывает `GET /api/cron`: сервер считает время намаза по координатам города и отправляет `notifications.sendSimple` (подпись: md5 отсортированных `k=v` + `secret_key`, см. `push_server.py`).
4. Лимиты и права для `notifications.sendSimple` уточните в поддержке ОК (метод доступен всем типам приложений, кроме игр).
5. Клиент хранит предпочтения в `localStorage` (`u_push`, `u_push_off`) — синхронизируйте с сервером при изменении.

## 5. Карточка каталога и модерация

- **Название**: Умма в ОК. **Категория**: Образ жизни. **Возраст**: 12+.
- **Описание**: время намаза по городу, календарь Хиджры и Рамадан, Коран с переводами, уроки основ, карта мечетей и молельных комнат (11 149 объектов, 1 392 города, источник gdenamaz.ru). Интерфейс на 9 языках.
- **Иконка**: PNG 512×512 (утверждённый логотип — зелёный градиент #0E8F6F→#14B8A6).
- **Скриншоты**: 3–5 штук (главная, Коран, карта мечетей, календарь).
- **Политика конфиденциальности**: страница на HTTPS; соответствие **152-ФЗ** («геолокация — только с согласия, расчёты на устройстве») — текст на экране «Настройки» → «О приложении».
- **Требования модерации** (apiok.ru/apps/rules): информационно-справочный сервис без миссионерской деятельности; источники указаны в приложении (переводы Кулиева/Крачковского/Османова, классические сборники хадисов, открытая база gdenamaz.ru).

## 6. Перед релизом — обязательные доработки

1. **Вычитка переводов носителями** — приоритет kk, uz, ky, tg, tt, ba; черновые: ce, av.
2. **Официальные переводы Корана** на языках аудитории (ru — Кулиев подключён; остальные языки — черновой перевод демо-аятов, до релиза подключить изданные переводы).
3. **Обновление базы мечетей**: поставьте периодическую синхронизацию с gdenamaz.ru (`/api/map` + `/api/v2/venues/<id>`) раз в месяц.
4. **Часовые пояса**: расширить встроенную таблицу CITY_TZ на все города (или определять пояс по геолокации устройства).
5. **Хранение закладок Корана** в ОК Storage вместо localStorage.
